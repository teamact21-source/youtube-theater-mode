# YouTubeシアターモード

YouTubeの動画ページを開いたときに、自動でシアターモードに切り替えるChrome拡張です。

## インストール

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. このREADMEが入っている `YouTubeシアターモード` フォルダを選びます。
5. すでに開いているYouTubeのタブは再読み込みします。

## 動作

- 通常の動画・ライブ配信の `/watch?v=...` ページが対象です。
- YouTube内で別の動画へ移動した場合も動作します。
- すでにシアターモードなら、そのままにします。
- 同じ動画の視聴中に手動で通常表示へ戻した場合は、その選択を尊重します。次の動画で再び自動切り替えします。
- 全画面表示中は切り替えず、ページ移動後の最大20秒間、プレイヤーの準備を待ちます。
- Shorts、埋め込みプレイヤー、モバイル版は対象外です。

設定画面や常駐バックグラウンド処理はありません。外部通信や視聴履歴の保存も行いません。
YouTubeの画面構造が変わった場合は、拡張の更新が必要になることがあります。

## 開発・確認

依存パッケージやビルドは不要です。編集後は拡張機能一覧でこの拡張の更新ボタンを押し、YouTubeを再読み込みしてください。

```sh
node --test tests/content.test.cjs
```

実機確認では、動画URLの直接表示、ホームからの動画選択、関連動画への移動、手動の表示切り替え、全画面表示、Shortsを確認してください。
